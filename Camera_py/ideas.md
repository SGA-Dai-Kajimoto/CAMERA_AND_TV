# やりたいことのアイディア

カメラで撮影した写真をテレビに移して表示させるためのアイディア比較。  
**アイディア2 が採用。**

---

## アイディア比較表

| アイディア | 概要 | ユーザーにとっての価値 | テレビであるメリット | 必要な技術 | シナリオ | ターゲット層 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1. 「みんなで撮る、すぐ見る」リアルタイム鑑賞会 | 撮影した写真が瞬時にテレビの大画面に映し出される。特に、集合写真で写りを確認しながら撮影できる体験は、HDMI接続の手間をなくし、大きな価値を提供します。 | - 撮った写真をその場で全員で見て盛り上がれる。<br>- 大画面で構図やピントを確認し、撮影クオリティを向上できる。<br>- 集合写真で写りを確認しながら撮影できる。 | - スマートフォンよりも大きな画面で、複数人で同時に写真を確認できる。<br>- 高画質・高精細なテレビであれば、写真の細部まで確認できる。 | - カメラとテレビのWi-Fi DirectまたはローカルWi-Fiネットワーク接続技術。<br>- 撮影直後の画像を低遅延で転送する技術（例：RTP/RTSP、WebRTC）。<br>- テレビ側で画像を表示するためのアプリケーション。 | - 家族や友人とのパーティーで、撮影した集合写真をその場で確認し、撮り直しや次のポーズの相談をする。<br>- 旅行先で、その日撮った写真をホテルのテレビに映し出し、一日を振り返る。 | - 家族（特に子供のいる家庭）<br>- 友人グループ<br>- 写真サークルなどのコミュニティ |
| ✅ 2. 「思い出を自動で整理・再生」インテリジェント・スライドショー **【採用】** | 転送された写真をテレビが自動で整理し、BGM付きのスライドショーを生成する。 | - 面倒な整理なしに、思い出をすぐに感動的なスライドショーとして楽しめる。<br>- 撮影場所や時間で自動的にアルバムを作成してくれる。<br>- 空間を彩るデジタルフォトフレームとして使える。 | - リビングの中心にあるテレビで、家族の思い出をBGM付きのコンテンツとして自然に再生できる。<br>- デジタルフォトフレームよりも大きく、迫力のある映像を楽しめる。 | - 画像認識AI（人物、風景、イベントなどを識別）。<br>- メタデータ（撮影日時、場所）の解析技術。<br>- スライドショー自動生成アルゴリズム（BGM選定、トランジション効果）。<br>- クラウドストレージとの連携。 | - 普段はテレビが消えている時間に、家族の思い出の写真をランダムにスライドショーとして再生し、生活空間を彩る。<br>- 祖父母の家で、孫の成長記録をまとめたスライドショーを上映し、家族団らんの時間を過ごす。 | - 忙しい子育て世代の家族<br>- デジタル機器の操作が苦手な高齢者層<br>- イベント（結婚式、誕生日会）の主催者 |
| 3. 「プロの視点を学ぶ」撮影アシスト機能 | テレビ画面に、より良い写真を撮るための補助線（三分割法など）やヒントを表示する。 | - 構図などを意識しながら撮影することで、写真の腕が上がる。<br>- 水平が取れていないなどの失敗を防げる。 | - 大画面で構図のバランスや水平を客観的に確認できる。<br>- 複数人で構図を相談しながら撮影できる。 | - カメラの向きや角度をリアルタイムに検知するセンサー技術（ジャイロセンサーなど）。<br>- 構図やアングルを評価し、アドバイスを生成する画像解析AI。<br>- テレビ画面上にガイドラインやヒントをオーバーレイ表示する技術。 | - カメラ初心者や子供が、ゲーム感覚で写真の撮り方を学ぶ。<br>- 物撮り（フリマアプリ出品用の商品撮影など）で、魅力的な写真を撮るためのガイドとして利用する。 | - 写真撮影の初心者<br>- 子供（親子で楽しむ）<br>- ブロガーやSNSユーザー |
