# Python Imaging Edge API テストアプリ用 Skill

## 概要
- Imaging Edge APIを用いたPythonテストアプリの開発・テスト・自動化支援用Skill

## 主な用途
- 認証フローの自動テスト
- ファイル操作APIの自動テスト
- ファイルアップロードAPIの自動テスト
- GUI操作の自動化（PyQt5等）

## 推奨環境
- Python 3.8以降
- requests, PyQt5 など必要なパッケージ

## サンプルタスク
- 認証情報の取得・検証
- ファイル一覧取得・検証
- ファイルアップロードの成否確認

## 注意事項
- テスト用トークンや個人情報はSkill内に記載しないこと
- テスト用設定ファイルは必ずgit管理外で運用
