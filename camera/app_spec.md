# アプリ仕様書

採用アイディア: **「思い出を自動で整理・再生」インテリジェント・スライドショー**

---

## 概要

カメラで撮影した写真を Imaging Edge クラウドに転送し、テレビがそれを自動で取得・整理して BGM 付きスライドショーとして再生するアプリ。

---

## ターゲット層

- 忙しい子育て世代の家族
- デジタル機器の操作が苦手な高齢者層
- イベント（結婚式、誕生日会）の主催者

---

## 実現する体験

| シナリオ | 説明 |
|---|---|
| デジタルフォトフレーム | テレビが待機中に、家族の思い出写真をランダムにスライドショーとして再生し、生活空間を彩る |
| 家族団らん | 祖父母の家で孫の成長記録をまとめたスライドショーを上映する |
| イベント | 結婚式・誕生日会で当日撮影した写真をリアルタイムで会場のテレビに表示する |

---

## 機能一覧

### 必須機能

| 機能 | 説明 |
|---|---|
| 写真の自動取得 | Imaging Edge クラウドから新しい写真を定期的に取得する |
| 自動整理 | 撮影日時・場所のメタデータを元にアルバムを自動生成する |
| スライドショー再生 | BGM・トランジション付きで写真を自動再生する |
| リモコン操作 | テレビのリモコンで再生・停止・スキップ・アルバム切り替えを行う |

### 将来対応（スコープ外）

| 機能 | 説明 |
|---|---|
| 画像認識による分類 | 人物・風景・イベントなどを AI で識別してアルバムを生成する |
| BGM 自動選定 | 写真の雰囲気に合わせた BGM を自動選択する |
| 写真編集 | 現時点では不要 |

---

## システム構成

```
[カメラ]
   ↓ Wi-Fi 転送
[Imaging Edge クラウド]
   ↓ API (GET /api/v1/folders, GET .../contents)
[テレビアプリ]
   ↓
[スライドショー表示]
```

---

## 利用 API

| 用途 | エンドポイント |
|---|---|
| 認証 | `POST /api/v1/oauth2/token` |
| ユーザー情報取得 | `GET /api/v1/user/me` |
| フォルダ一覧取得 | `GET /api/v1/folders` |
| コンテンツ一覧取得 | `GET /api/v1/folders/{folder_id}/contents` |
| コンテンツダウンロード | `GET /api/v1/folders/{folder_id}/contents/{content_id}/resources/{kind}/binary` |

詳細は `../docs/api_spec_summary.md` を参照。

---

## 非機能要件

| 項目 | 要件 |
|---|---|
| 新着写真の反映遅延 | 撮影から表示まで 60 秒以内（ポーリング間隔に依存） |
| オフライン対応 | クラウド未接続時は既取得の写真のみで再生する |
| 操作性 | リモコンのみで全操作が完結すること |
