# 2026-09-15 説明動画の黒画面調査

## Did

- BRAVIA_4K_AE3、Android System WebView 152.0.7977.87 で、チュートリアルの「TVで動画を見る」を実行。
- adb logcat、スクリーンショット、WebView の DevTools Protocol で再生状態と DOM のサイズを確認。
- ソース・APK を変更せず、実行中ページの HTML 要素の高さだけを一時変更して比較した。

## Got

- 黒画面でも YouTube の初期化は成功し、`state 1`（再生中）が記録された。DOM 調査時には一時停止状態で再生時刻 63.92863 秒、全長 195 秒だった。
- ネイティブ WebView は 1920x956px、JavaScript の viewport は 960x478 CSS px。一方、HTML・BODY・動画 iframe の実測高さはすべて 0px。
- 読み込まれた CSS は `HelpVideoOverlay.kt` の `html, body { height:100%; }` と `#player { height:100%; }` に一致した。
- HTML 要素を一時的に `height:100vh` に変えても高さは 0px のまま。`innerHeight` の実測値を使って `height:478px` を指定すると、3 要素とも高さ 478px になり、スクリーンショットで説明動画の映像が表示された。
- 直接原因は動画の表示領域が高さ 0 に潰れていたこと。YouTube の再生状態だけでは映像表示の成功を判定できない。
- 相対高さが 0 になる内部要因（AndroidView / WebView の測定制約など）は未確定。デコーダー故障や埋め込み origin のエラーを今回の原因とはしていない。

## Next

- WebView のレイアウト・測定条件を確認し、HTML の表示領域が実際の画面サイズに追従する恒久修正を行う。478px の固定値を製品コードに入れない。
- 動画の開き直し、再生・一時停止、シークを実機で確認する。診断用 CSS は実行中ページだけの変更で、恒久修正・APK の更新は未実施。
